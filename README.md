# HabitHero – Habit Tracker

HabitHero is a REST API for managing personal habits,
developed as part of a university project.

## Project Description

HabitHero helps users organize and track their
personal habits, such as studying, exercising,
or reading.

## Technologies

- Java 17
- Spring Boot
- Maven
- REST API
- JSON

## Current Features

- Habit entity with basic attributes
- GET endpoint returning sample habits

## API Endpoint

GET /api/habits

Returns a JSON list of example habits.

## Future Features

- Create, update, and delete habits
- Track daily progress
- Store habits in a database
- Display habit statistics
